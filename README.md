# ⚙️ Django Setup

Projeto desenvolvido para praticar a configuração inicial de aplicações utilizando o framework **Django**, explorando os fundamentos da estruturação de projetos backend com Python.

## 🎯 Objetivo

Compreender o processo de configuração de um projeto Django e aplicar conceitos fundamentais para a criação e organização de aplicações web.

## 🛠️ Tecnologias utilizadas

- Python
- Django

## 📚 Conceitos praticados

- Configuração de projetos Django;
- Estrutura de aplicações web;
- Organização de arquivos e diretórios;
- Configuração de URLs e views;
- Fundamentos do desenvolvimento backend com Python.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/N1c0llyy/Django-Setup.git
```

### 2. Acesse o diretório

```bash
cd Django-Setup
```

### 3. Instale o Django

```bash
pip install django
```

### 4. Execute o servidor

```bash
python manage.py runserver
```

A aplicação estará disponível em:

http://127.0.0.1:8000/
